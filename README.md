# CryptoLabX

## Cryptography Laboratory (22CPP307)

### Project Description

CryptoLabX is a modular cryptography toolkit developed as part of the Cryptography Laboratory course. The objective of this project is to create a reusable framework that will be extended throughout the semester with classical cryptographic algorithms, modern encryption techniques, cryptanalysis tools, mathematical utilities, and security analysis modules.

Currently, the project provides a menu-driven command-line interface, file analysis utilities, dataset management, and execution logging. Future assignments will build upon this foundation by implementing encryption, decryption, attacks, and statistical analysis.
